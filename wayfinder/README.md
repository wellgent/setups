# Coordinate agentic work with wayfinder

Take complex work from a loose idea to done, across as many sessions and agents as it takes.

The steps are on [wellgent.ai/setups/wayfinder](https://wellgent.ai/setups/wayfinder).

## Files

Each file is listed under the step that uses it, with where it goes.

### Install Matt's skills

- [`repo/skills-lock.json`](repo/skills-lock.json) goes to `skills-lock.json` in the repo you set up

### Connect wayfinder to your issue tracker

- [`repo/docs/agents/issue-tracker.md`](repo/docs/agents/issue-tracker.md) goes to `docs/agents/issue-tracker.md` in the repo you set up
- [`repo/AGENTS.md`](repo/AGENTS.md) goes to `AGENTS.md` in the repo you set up
