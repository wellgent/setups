# Terminal setup

An opinionated terminal setup to use across machines, Mac or Linux.

The steps are on [wellgent.ai/setups/terminal](https://wellgent.ai/setups/terminal).

## Files

Each file is listed under the step that uses it, with where it goes.

### Make zsh your shell

- [`home/.zshrc`](home/.zshrc) goes to `~/.zshrc`
- [`home/.zprofile`](home/.zprofile) goes to `~/.zprofile`

### Set up the prompt

- [`home/.config/starship.toml`](home/.config/starship.toml) goes to `~/.config/starship.toml`
